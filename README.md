# 정령계약자 (가제)

**정령사**가 되어 야생 정령을 **디스펠**로 계약하고, 전투에서 **소환**해 싸우며,
장비를 입히고 레벨을 올려 **진화**시키는 세로 화면 헥스 턴제 SRPG. 90년대 정령 수집형 SRPG에서 영감을 받은 오리지널 프로젝트입니다.

- 엔진: **Godot 4.3+** (GDScript, GL Compatibility 렌더러)
- 플랫폼: Android 우선 (720×1280 세로, 화면비에 따라 확장)
- 그래픽: 현재는 도형 + 텍스트. 아트는 시스템 확정 후 입힐 예정

## 프로토타입 v0.2 기능

| 시스템 | 내용 |
|---|---|
| 정령사 | 플레이어 본인. 전장에 직접 서며, **쓰러지면 패배**. 이름·속성을 정해 시작 |
| 소환 | 정령사 옆 빈 칸에 계약 정령을 불러냄 (MP 소모, 같은 속성 할인). 소환된 다음 라운드부터 행동 |
| 귀환 | 정령사가 정령을 불러들이거나, 정령이 스스로 돌아감. HP는 유지되고 다시 소환 가능 |
| 선봉 | 계약 정령 목록의 첫 번째(★)는 전투 시작 시 자동 소환 |
| 헥스 전투 | 8×10 육각 맵, 무작위 지형, 속도 순 턴, 이동 1회 + 행동 1회 |
| 지형 | 숲·물가·언덕·용암지대·바위 (아래 표). 빈 칸을 누르면 지형 정보 표시 |
| 행동 | 정령사: 소환 · 귀환 · 디스펠 · 공격 · 대기 · 후퇴 / 정령: 공격 · 스킬 · 귀환 · 대기 |
| 디스펠 | 정령사 전용. 사거리 2, MP 4. 성공률 = 대상 체력이 낮을수록↑, 정령사 레벨 차이, 속성 상성, 종족 계약난이도 |
| 속성 | 불 > 바람 > 흙 > 물 > 불 (유리 ×1.5 / 불리 ×0.75) |
| 정령 | 16종 (4속성 × 2계열 × 2단계). 레벨 도달 시 자동 진화, 레벨업 시 스킬 습득 |
| 장비 | 무기 / 장신구 2슬롯, 8종. 승리 시 40% 확률 드랍 |
| 성장 | 정령사도 레벨업. 동시 소환 수 2 → Lv5 3마리 → Lv10 4마리. 소환하지 않은 정령은 경험치 30% |
| 거점 | 정령사 정보, 계약 정령(최대 6) / 보관함 관리, 선봉 지정, 정령 상세(능력치·스킬·진화·장비·소환 MP) |
| 저장 | `user://save.json` 자동 저장 |
| 적 AI | 이동 가능한 칸 × 행동 × 대상 전부 평가해 기대 피해/처치 우선, **정령사를 우선 노림** |

### 지형 (`data/terrain.json`)

| 지형 | 이동 비용 | 효과 |
|---|---|---|
| 평지 | 1 | 없음 |
| 숲 | 2 (흙 1) | 받는 피해 −20% |
| 물가 | 2 (물 1) | 물 정령 주는 피해 +20%·매 라운드 HP 10% 회복 / 불 정령 주는 피해 −20% |
| 언덕 | 2 (바람 1) | 바람 정령 주는 피해 +20% · 원거리 스킬(최대 사거리 2 이상) 사거리 +1 |
| 용암지대 | 1 | 불 정령 주는 피해 +20%·매 라운드 HP 10% 회복 / 그 외 매 라운드 HP 8% 화상 |
| 바위 | — | 통과 불가 |

적 AI도 지형을 고려해 엄폐·회복 칸을 선호하고 용암을 피합니다.

타겟팅 중에는 대상 위에 **예상 피해** 또는 **디스펠 성공률(%)**이 표시됩니다.

## 실행 방법

1. [Godot 4.3 이상](https://godotengine.org/download) 설치 (표준 버전, .NET 아님)
2. Godot에서 `project.godot` 가져오기 → **F5** 실행
   - 전투만 테스트하려면 `scenes/battle.tscn` 열고 **F6**

## Android 빌드

1. Godot 에디터: **편집기 → 내보내기 템플릿 관리**에서 템플릿 설치
2. JDK 17 + Android SDK 설치 후 **편집기 설정 → 내보내기 → Android**에 경로 지정
   (디버그 키스토어는 Godot가 자동 생성)
3. **프로젝트 → 내보내기 → Android** 프리셋 선택 → APK 내보내기 (`build/spirit-contract.apk`)
   - `export_presets.cfg`에 `data/*.json`이 포함되도록 설정돼 있습니다
4. USB 디버깅 켠 폰을 연결하면 에디터 우측 상단 Android 버튼으로 바로 실행 가능

## 폴더 구조

```
data/                 밸런스 데이터 (정령·스킬·장비) — 코드 수정 없이 조정 가능
scenes/               main_menu / hub / battle (UI는 스크립트에서 생성)
scripts/autoload/     GameData(데이터·상성·테마), GameState(진행·저장)
scripts/core/         Spirit (능력치·경험치·진화·직렬화), Summoner (정령사: 소환 비용·한도)
scripts/battle/       HexGrid(좌표·거리·이동범위), BattleLogic(공식), battle.gd(전투 씬)
scripts/ui/           UIKit(헬퍼), 타이틀, 거점
```

## 주요 공식 (`scripts/battle/battle_logic.gd`)

- 피해 = 공격 × (위력/40) × 20/(20+방어) × 속성배율 × 지형배율 × (0.9~1.1)
- 디스펠 = 0.15 + (1−HP비율)×0.6 + 레벨차×0.04 (+0.1 속성 유리) × 종족 계약치, 5~95%
- 필요 경험치 = 8 + 레벨² × 4, 처치/계약 보상 = 6 + 적 레벨 × 4
- 소환 MP = 4 + 정령 레벨 (정령사와 같은 속성이면 ×0.7) — `data/summoner.json`에서 조정
