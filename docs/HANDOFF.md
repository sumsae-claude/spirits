## 1. ⚠️ 중요한 제약

- **Godot 실행 가능** (사용자가 허락함): 클라우드에서 공식 바이너리를 받아 헤드리스로 실행한다. 받는 법:
  `curl -sSL -o g.zip https://github.com/godotengine/godot/releases/download/4.3-stable/Godot_v4.3-stable_linux.x86_64.zip && unzip g.zip` (스크래치 폴더에)
  - 임포트·컴파일 확인: `godot --headless --path . --import`
  - **자동 플레이 테스트**: `godot --headless --path . res://tests/smoke_test.tscn` (새 게임 → 1-1 튜토리얼 → 1장 → 대륙 지도 → 2장, 20분 넘게 걸리니 백그라운드로). `SCRIPT ERROR` 줄이 버그, `SMOKE FAIL`이 진행 실패
  - 한 스테이지 승률: `SMOKE_STAGE=1-6 SMOKE_TRIES=4 godot --headless --path . res://tests/smoke_test.tscn`
  - 주의: 테스트 봇은 단순해서(정령사는 소극적, 정령은 적 AI를 빌려 씀) 보스 밸런스는 사람 플레이로 확인할 것
- 화면(손맛·레이아웃)은 헤드리스로 못 본다 → 사용자 실행 피드백 우선.
- GDScript 작성 시 주의: `:=`로 Variant 값을 추론하지 말 것(타입 명시), `min/max` 대신 `mini/maxf` 등 사용.
- 데이터 파일(JSON)을 바꾼 뒤에는 Python으로 JSON 유효성과 참조를 검사하고, 가능하면 자동 플레이 테스트도 돌릴 것.
- 커밋 메시지는 한국어. 클라우드 세션이 정한 작업 브랜치에 push → 사용자가 원하면 main에 병합(이번 세션은 사용자 요청으로 매번 main 병합).

## 2. 현재까지 구현된 것 (v0.8+)

### 전투 (`scripts/battle/battle.gd` — 가장 큰 파일)
- **8×12 헥스**(칸 46px, v0.9에서 8×10→확대), 지형(숲·물가·언덕·용암·마법진·바위) 효과, 스토리 스테이지는 시드 고정 맵
- 라운드 = **아군 턴(유닛 자유 순서) → 적 턴(속도순)**, 이동 1 + 행동 1, 이동 미리보기(파란 칸 2번 탭)·이동 취소
- **정령사**가 직접 출전(쓰러지면 패배): 소환(연속 소환, 한도 3+4레벨마다+1, 최대 6)/귀환/디스펠(사거리 2)/정령사 스킬/공격
- 상성 **바람 ▶ 불 ▶ 풀 ▶ 물 ▶ 바람** (×1.5/×0.75), 적 칸 색으로 유리(초록)/보통(노랑)/불리(회색) 표시
- 적 정령사 AI(거리 유지·상성 소환·회복/공격 스킬), 적 정령사의 정령도 디스펠 가능(×0.6)
- 수호 정령 보스: HP 1 아래로 안 떨어짐, 30% 이하에서 "실이 드러나" 디스펠 가능(+30%)
- 버프/디버프, 대상 탭 → 행동 메뉴(예상 피해·성공률·반격 표시), 사용 불가 버튼 흐리게
- **(최신) 연출**: 근접 돌진+베기, 스킬 기모으기+속성별 투사체(불=불덩이/물=물줄기/풀=잎/바람=초승달)+폭발, 디스펠 금빛 실, 피격 붉은 번쩍+흔들림, 소환 마법진+빛기둥+통 등장, 쓰러짐 빛 입자로 흩어짐, 계약/귀환 금빛 고리로 사라짐, 회복/버프/디버프 이펙트 (`_draw_fx`, `_anim_*`, `_vanish`)
- **반격**: **공격 탭**의 공격(기본 공격·정령 스킬·정령사 공격 스킬)을 받고 살아남은 쪽은, 공격자가 바로 옆(거리 1)이면 기본 공격 60% 위력으로 반격(`BattleLogic.COUNTER_RATIO`). 떨어져서 원거리 스킬로 치면 반격 없음. 정령사 스킬(회복·버프·디버프)·디스펠은 반격 없음. AI도 반격 피해 고려
- **(최신) 공격 탭** (사용자 확정 규칙): 정령 = 기본 공격 + 스킬 최대 2개 (정령에게 '스킬' 메뉴는 없음). 정령사 = 기본 공격 + 속성 공격 스킬 + 디스펠, 나머지 정령사 스킬은 '스킬' 메뉴. 진화 전 정령은 거의 기본 공격만(빨리 진화하는 계열은 0개, 늦게 진화하는 계열은 Lv6에 약한 스킬 1개), 진화형은 스킬1 바로 + 스킬2 Lv12/15
- **(최신) 히든 스킬 + 수동 진화**: 진화는 자동이 아니라 거점 상세 화면의 '진화시키기' 버튼. 진화 레벨 + 5(`Spirit.HIDDEN_SKILL_GAP`)까지 진화하지 않으면 종족별 숨은 기술(`spirits.json` `hidden_skill`, `skills.json` `"hidden": true`)
- **(최신) 명령 메뉴**: 원작처럼 유닛 옆에 세로 메뉴(공격 ▸ / 스킬 ▸ / 소환 ▸ / 귀환 / 대기 / 이동 취소). 적을 누르면 그 적 옆에 행동 목록. 아래 패널은 유닛 정보·안내·행동 설명만. '턴 종료'는 위쪽 HUD, 후퇴·도움말은 '≡' 메뉴
- **(최신) 배속**: 오른쪽 위 HUD 버튼 ▶×1 / ▶▶×2 / ▶▶▶×3 순환 (`Engine.time_scale`, `GameState.flags.battle_speed`)
- **(최신) 전투 화면 개편**: 지역별 도트 배경 `assets/battle/bg_<속성>.png` + 지형 헥스 타일 `tile_<지형>.png` (`tools/art/battle_bg.py`로 생성). 평지는 배경이 비치고, 이동/대상 표시는 반투명 덧칠(`_cell_overlay`). 위쪽 HUD(라운드 알약·`?` 도움말·배속), 아래 명령 패널은 맵 바로 아래부터 화면 끝까지(긴 화면은 패널이 커짐). 상성·지형 범례는 `?` 도움말로 이동. 배치 참고 이미지: `art/battle_layout_mock.png`
- **(최신) 1-1 고정 튜토리얼 스테이지**: `stages[0]`에 `terrain`(고정 지형), 적 `cell`(고정 위치), `script`(단계 목록). 처음 깰 때만 스크립트 진행 — 정령 선택 → 지정 칸 이동 → 유리한 적 기본 공격 → 정령사 선택 → 지정 칸 이동 → 디스펠(반드시 성공, 대상은 HP 1 밑으로 안 떨어짐) → 적 턴 대기 → 방금 계약한 정령 소환 → 자유 전투. 진행 중엔 지시한 칸/대상/메뉴 버튼만 동작(`_script_tap`, `_script_allows`, `_add_action`의 kind). 엔진: battle.gd "고정 튜토리얼 스크립트" 구역
- **(최신) 전투 중 계약한 정령은 다음 차례부터 바로 소환 가능**, HP는 깎인 그대로 (원작 고증)
- **(최신) 소환 = 계약 정령 전체**(파티 + 보관함 + 방금 계약): 소환을 고르면 아래 패널이 소환 목록(속성 탭, 지금 적에게 유리한 정령 → 레벨 순, 못 쓰는 정령은 흐리게 아래로). 동시 소환 수 제한(3~6)은 그대로
- **(최신) 귀환**: 정령사 메뉴엔 없음. 정령이 정령사 바로 옆 칸이나 마법진 위일 때만 '귀환' (`_can_recall`)
- **(최신) 마법진 진영 색**: 우리 편 파랑 / 적 정령사·그 정령 빨강 / 야생 정령은 원래 보라. 비면 마지막 색 유지. 바뀔 때 색 번짐·별 회전·고리 맥박·빛 입자 (`_update_circles`, `_draw_circle_mark`)
- **(최신) HUD**: `[턴 종료] [후퇴(확인 창)] [?] [▶배속]`. 명령 메뉴 버튼은 글자 폭에 맞춰 좁게(최소 132px)
- 상성 튜토리얼용 적 배치: 1-1 = 고향 속성이 이기는 정령(`@prey_a`, 초록) + 같은 속성(노랑), 1-2 = 고향 속성에 강한 정령(`@strong_a`, 회색) 포함. 튜토리얼 focus `advantage`/`disadvantage`가 그 적을 가리킴
- **(최신) 전투 중 튜토리얼**: `chapter1.json`의 `tutorials` (스테이지별 + `"*"` 공통). 이벤트(start/select/moved/choose/weak/captured/counter/enemy_phase/round2/revealed)에 맞춰 화자 초상화 말풍선 + 가리키는 칸 금테·화살표. 한 번 본 단계는 `flags.tut_<id>`. 예전 대화 속 "▶ 조작 설명" 줄은 삭제
- 호흡: 적 행동 간격 0.25초, 야생 정령은 2행에서 출발. (피해 1.3배는 사용자 요청으로 되돌림 — 능력치가 오르면 자연히 빨라진다는 판단)
- 도트 스프라이트(정령 20 + 정령사 4) 표시, 대기 모션, 행동 끝난 유닛 어둡게

### 대규모 수정 A단계: 원작식 전투 핵심 (사용자 확정, 참고: docs/reference/original_systems.md)
- **HP·MP 상한 99** (`Spirit.VITAL_CAP`), 속성별 성장 비율(불=공·방, 바람=속·MP, 풀=방·HP, 물=MP·속), **레벨업 시 HP·MP 전부 회복**
- **적 레벨이 정령사 레벨을 따라감**: (정령사 Lv − 권장 Lv)의 절반, 최대 ±3. 스테이지가 정한 종족 모습은 유지(`_scaled_spirit`). 1-1 첫 튜토리얼은 보정 없음
- **명중·회피**: 스킬 `hit`(1스킬 85, 2스킬 75, 3스킬 65, 숨은 기술 75) + 레벨×0.5, 상성 ±20, 지형 등급, 방어 중이면 민첩 회피 (`_hit_chance`)
- **반격 / 방어 대응** (`_tab_attack`, `_choose_response`): 방어 = 받는 피해 ×0.5(정령사 공격 마법 제외)+회피, 반격 = 살아남고 바로 옆이면 되받아침. 적 AI는 맞으면 쓰러질 때·반격 못 할 때 방어. 아군은 설정 3가지(`flags.response_mode`: counter/defend/ask) — '?' 도움말에서 바꿈. 사용자가 3가지를 직접 해 보고 고르기로 함
- **지형 5단계** (`terrain.json` grade, `GameData.terrain_grade`): ◎+20 ○+10 =0 △−10 ×−20 → 공격 피해·받는 피해·명중 보정, 불리 지형은 이동 비용 2. 마법진은 누구나 +20. 이동 칸에 표시
- **소환 유지비** (`spirits.json` cost: 진화 전 1, 진화형 2, 수호 0): 라운드마다 정령사 MP에서 빠짐. 모자라면 그 정령이 **폭주해 야생**(디스펠로 되찾음, 전투 후엔 보관함에 남음, 친밀도 −15). 정보창에 유지 MP·⚠MP부족
- **친밀도** `Spirit.affinity` 0~100(저장됨): 소환 +4, 전장에 있는 라운드마다 +1, 귀환 −5, 쓰러짐 −10. 다른 정령사의 디스펠 성공률 ×(1 − 친밀도/125). **적 정령사도 디스펠로 내 정령을 빼앗음**(HP 40% 이하·성공률 25% 이상일 때, 되찾을 수 있음)
- **상태이상 5종** (`BattleUnit.status`): 독(라운드마다 최대 HP 10%), 잠(행동·반격 불가, 회복되면 깸), 혼란(제멋대로, 적 턴에 움직임), 지체(이동 1), 석화(행동·반격 불가, 회색). 정령사는 혼란·석화 면역. 스킬 데이터 `status`(확률·3라운드). 해제: 시간, 정령사 스킬 '정화의 빛'(`purify_light`)
- 원작 데이터 시트(사용자 제공 구글 시트, 종족 표)에서 **수치 규모만** 참고: 1~3스킬 기본 명중 약 80/70/60, 코스트 평균 3, 이동 땅 5.6 < 불 5.9 < 물 7.1 ≈ 바람 7.2

### 최신 변경 2 (사용자 확정)
- **저장**: 0번 = 자동 저장 칸(`save_game()`, 전투 후·지도 이동), 1~99번 = 직접 저장 (`save_to_slot`, `load_slot`, `slot_info`, `latest_slot`). 옛 `user://save.json`은 자동 칸으로 옮김. 창 = `SaveSlots.open(parent, "save"/"load")` (거점·마을 저장, 타이틀 불러오기). 덮어쓰기는 한 번 더 눌러 확인
- **레벨업 표시**: 전투 중 "LEVEL UP! Lv.5 (+1)", 결과 "경험치 +42  Lv.4 → Lv.6 (+2)"
- **SpiritList**: 카드 위에서 끌어도 스크롤(터치는 ScrollContainer, PC 마우스는 직접 처리), 끈 뒤엔 선택 안 됨, 굵은 스크롤 막대, 정렬 방향 ▲/▼ 버튼(`list_rev_<ctx>`)
- **상성 표시**: 칸 색칠은 지금 자리에서 공격 가능한 적만. 상성 자체는 적 머리 위 ▲(유리)/▼(불리) 아이콘 (`_draw_advantage_marks`)
- **1-1 소환 단계**: 화면에 따라 대사 3종(`t` 메뉴 / `t_sheet` 소환 창 / `t_place` 칸 고르기, `script_sub`). 첫 소환 창 안내(`*` summon_sheet)

1. **유닛 정보 창을 오른쪽 위로**: 위쪽 HUD(턴 종료·후퇴·?·배속) 배속 버튼 아래에 **'유닛정보'** 버튼. 누르면 그 아래에 지금 유닛의 상태창(`_status_card`)이 펼쳐지고, 다시 누르면 숨김. 펼친 동안 다른 유닛을 누르면 그 유닛 정보로 바뀜. 아래 패널의 상태창은 빼고 안내·기록만 (열림 여부는 flags에 기억). 사용자는 가로 화면(태블릿)에서도 플레이 — 양옆 여백이 넓음
2. **공격 선택 창에는 공격 탭만**: 정령사의 '스킬'(지원·약화 등, 반격을 받지 않음)은 공격 선택 창 목록에서 빼고 스킬 메뉴(`스킬 ▸`)에서만 쓰기. 공격 선택 창 = 기본 공격 · 공격 탭 기술(정령 스킬, 정령사 공격 마법) · 디스펠. (`_target_options`에서 적 대상 support skill 추가 부분을 확인창 경로에서 제외)
3. **디스펠도 전투 연출 창**: 정령사 → 대상에게 금빛 실이 뻗는 연출(`DuelView`), 성공률 표시, 성공 = 금빛 고리로 감싸며 사라지고 "GET!", 실패 = 실이 끊기고 "저항!". 적 정령사의 디스펠(내 정령을 빼앗음)도 같은 창. 연출 끄기 설정을 따름
4. **아이템 획득 팝업**: 전투 중 보물 칸을 밟거나 쓰러뜨린 정령이 재료를 떨어뜨리면 가운데에 작은 팝업(아이콘·이름·종류·설명, "가방에 들어감")을 띄우고 눌러서 닫기. 채집·이벤트·의뢰 보상도 같은 모양으로 통일
5. **아이템·장비를 원작 구조로 확장** (사용자: "완전 파쿠리는 아니어도 장비탭 포함해서 어느 정도는 따와 줘", 원작 합성창 스크린샷 참고)
   - **탭 5개**: 무기 · 장비(반지·목걸이 등) · 약품(회복) · 특수(부적·향·전투용) · 이벤트(이야기 아이템). 합성창·가방·상점·소지창 고르기 모두 같은 탭
   - **합성창**: 왼쪽 = 탭별 아이템 칸(아이콘 + 효과 요약 "HP+20" "MP+10" "혼란 회복" + 보유 수), 오른쪽 = **재료 A + 재료 B = 결과**(원작처럼 2개 조합, 지금의 솥 3종류·5개 방식 대체) + 확인/취소, 아래 = 상세(이름·속성·사거리·범위·명중·공격력·HP/MP 회복·지속 턴·가격·특수 효과, 장비 수치 STR(공)/AGI(속)/DEF(방)/INT(MP)/코스트/이동/사정/소비 MP, 누가 쓸 수 있나)
   - **레시피 표**: 재료 × 재료 격자, 모르는 칸은 "?" (원작 합성표처럼)
   - **수치 규모는 원작 데이터 시트 참고**(시트: 아이템 약 365개, 조합 약 640개, 속성별 꽃·향수·가루·수정 계열, 장비에 HP/MP 라운드 회복 수치도 있음) — 이름·아이콘은 새로 만듦. 목표 아이템 100~150개, 레시피 200개 안팎
   - 장비창(소지 3칸 고르기)도 같은 탭·칸 모양
6. **상점도 원작 구조로** (사용자 스크린샷: 완전히 같을 필요는 없지만 **모든 종류를 섞어 판다**는 점은 반영)
   - 같은 5개 탭(무기·장비·약품·특수·이벤트), 칸마다 아이콘 + 핵심 수치("공+5", "이동+1", "코스트-1", "소비MP-1") + 가격
   - 파는 것: 반지·목걸이 같은 장신구, 나뭇가지·광석·결정 같은 재료(재료도 약간의 능력치가 있어 장착 가능), 이동+/코스트−/소비MP− 장신구, 검 등 무기, 회복약 — 상점마다 구성이 다름(원작 시트 '상점' 탭 참고)
   - '상점 물건 / 내 물건' 전환(팔기), 수량 정해서 사기·팔기, 상인 초상화·이름, 아래 상세(합성창과 같은 상세 칸), 버리기
7. **전투 맵을 원작처럼 크게 + 전체지도** (사용자 스크린샷: 원작은 한 판 맵이 화면보다 훨씬 큼, 오른쪽에 전체지도 창)
   - 맵 크기를 스테이지 데이터에서 정함(`size`), 기본 지금의 약 4배(예: 16×24). 화면은 **카메라**: 한 손가락 끌기 = 이동, 두 손가락(또는 휠) = 확대·축소, 고른 유닛·적 턴에 움직이는 유닛으로 자동 이동
   - **'전체지도' 버튼**: 유닛정보 버튼 옆(오른쪽 위). 누르면 맵 전체 축소판(지형 색 + 아군 파랑/적 빨강 점 + 지금 보이는 범위 네모)이 펼쳐지고, 누른 곳으로 카메라 이동. 다시 누르면 숨김. 유닛정보와 둘 다 열 수 있음
   - 함께 손볼 것: 지형 자동 생성·스테이지 고정 지형 좌표, 적 배치·소환 칸, 적 AI의 접근(먼 거리), 튜토리얼 칸 지정, 명령 메뉴·확인창 위치(카메라 기준), 테스트 봇
8. **정령 보관소를 원작처럼 '정령들이 모여 있는 마당'으로** (사용자 스크린샷: 돌바닥 위에 계약 정령 도트가 서 있음, 위에 속성 탭 불·바람·풀·물 + 끝)
   - 거점의 보관함: 카드 목록 대신(또는 전환 버튼으로) 바닥 타일 위에 정령 도트를 줄지어 세움, 살짝 움직이는(숨쉬기) 연출, 속성 탭으로 거르기
   - **진화 가능한 정령 머리 위에 "OK!"** 표시 → 누르면 상세(능력치, **진화 전 → 후 능력치 비교**, 새 스킬) + [진화] 버튼 → 진화 연출(빛) 후 새 모습
   - 많아지면 스크롤(끌기). 선봉 표시(★)도 도트 위에

## C단계: 아이템 시스템 (완료, 사용자 확정 설계)
- 데이터 `data/items.json` (kind: equip 장비 / tool 도구 / material 재료), 합성표 `data/recipes.json` (비공개). `equipment.json`은 없앰. `GameData.items`(전부)·`GameData.equipment`(장비만)·`item_info`·`element_material`·`random_tool`
- **소지창 3칸** `Spirit.items` (장비·도구 아무거나, 옛 저장 무기·장신구 → 1·2칸으로 이전 `load_items`). 나머지 = 공용 가방 `GameState.inventory`. 편집 `EquipEditor`(거점 상세·전투 소환 창)
- 같은 장비 여러 개 → 능력치 쌓임. **특수 장비는 전투당 1회**: 부활의 깃털(`special: revive`, 쓰러지면 **HP 가득** 부활, `BattleUnit.revive_used`), 계약의 방울(`bind`, 디스펠 +10%)
- **전투 '도구 ▸'**: 도구마다 사거리/범위(`range`, `area`). 회복약 0~1 / 상급 0~1 반경1 / 최상급 0~2 반경2, 마력수, 정화초, 불씨·물보라 부적(적 1~3칸, 반드시 맞음), 매듭 향(정령사, 다음 디스펠 +20%). 보라색 칸. 쓰면 사라지고 행동 끝 (`_use_item`, `_item_targets`)
- **적도 도구 사용** (`GameState._arm_enemies`: 정령 30%, 적 정령사는 늘 회복약 / AI `_enemy_try_item`: 다친 아군 회복·잠 풀기·마무리 공격). 디스펠로 계약하면 들고 있던 도구도 따라옴
- **줍기**: 전투 맵 보물 칸 1~2개(올라서면 획득, 그 이동은 되돌릴 수 없음) · 쓰러뜨린 정령 45% 속성 재료 · 승리 50% 재료 → 전투 끝에 가방으로. 지도 **채집 지점** `type: gather` (1장 `side_nodes`의 약초 언덕, 2장 안개 낀 샘터), 승리 2회마다 다시 (`GameState.gather`)
- **가방 · 합성** `CraftScreen` (거점 첫 화면 버튼 + 마을 '합성'): 솥에 3종류·5개까지, 맞으면 결과물 + '알게 된 레시피'(`GameState.known_recipes`, 저장됨), 틀리면 재료 1개 잃음. 아는 레시피는 눌러서 바로 채움
- 상점: 장비 외에 회복약·마력수·정화초·약초는 늘 판다. 새 게임: 정령사 소지창에 회복약
- 아직 안 함: 장비 강화(+1~+5)

## 원작식 전투 창 (사용자 영상·스크린샷 참고, 최신)
- **이동 범위 = 흰 테두리 육각형**(지형이 비침), 미리보기 칸은 금테. **정령사 이동력 3 → 5** (원작은 정령사가 정령보다 멀리 감)
- **'공격 선택' 창** (`_show_attack_confirm`): 적을 누르면(또는 공격 탭에서 기술 고르고 대상을 누르면) 열림. 왼쪽 = 내 공격 목록(기본 공격·스킬 / 정령사: 기본 공격·공격 마법·**디스펠 GET 성공률**·적 대상 스킬)과 명중·피해, 오른쪽 = 상대 예상 대응(반격/방어), 가운데 비교 카드(사거리, ▶명중%·피해 / 반격 피해·명중% ◀, HP 막대에 예상 피해 붉게, 마스터). 확인/취소. 튜토리얼 스크립트 중에는 예전 메뉴
- '매번 묻기' 대응도 같은 모양의 '방어 선택' 창 (`_fill_defence_window`)
- **명중률 화살표** `HitArrow` (`scripts/battle/hit_arrow.gd`): 길이 = 명중률, 빨강 → 내 공격 / 파랑 ← 상대 반격, 글자(명중 n% · 피해 m) 크기 양쪽 동일. 빈 틀은 그리지 않음(사용자 요청). 기술 목록 숫자도 상대가 방어할 것 같으면 방어 기준
- MP 소비 표시: 공격 선택 창 MP 막대 "32→22", 연출 창 MP 막대가 줄며 "MP-10"
- **'전투 중' 연출 창** `scripts/battle/duel_view.gd` `DuelView`: 공격마다 두 유닛을 작은 전장에 띄워 돌진/투사체 → 피격·빗나감 → "반격!" → 반격. 화면 누르면 넘김, '?' 도움말에서 끄기(`flags.battle_anim`). 튜토리얼 스크립트 중엔 끔
- 화면 확인: `xvfb-run -a -s "-screen 0 720x1280x24" godot --path . --resolution 720x1280 --rendering-driver opengl3 res://tests/screenshot.tscn` (SHOT_DIR 폴더에 상태창·이동 범위·공격 선택·연출 PNG). 스모크 전체 실행은 연출 창 끔(`SMOKE_ANIM=1`이면 켬)
- 테스트 봇 결과(참고): 1장 1-1~1-4 승리, 1-5는 봇 승률 1~2/4 (정령사가 혼자 앞에 서는 단순한 봇이라 보스급은 사람 플레이로 판단), 2장 2-1~2-4 승리, 2-5 보스는 봇이 짐
- **유닛 상태창** (`_status_card`): 도트 + 이름·Lv·속성 + HP/MP 막대 + EXP, 능력치, **공격 3칸**(명중·위력·사거리·MP), **소지품 3칸**, 정령사는 속성별 소환 정령 수·**다음 턴 MP(+회복 −유지비)**. 빈 칸을 누르면 속성별 지형 등급(원작 지형 창처럼)

### 최신 변경 (사용자 확정 규칙)
- **명령 메뉴**: 유닛을 고른 직후엔 메뉴 없이 이동 범위만. 이동하면 메뉴가 뜨고, 유닛을 한 번 더 누르면 '제자리에서 행동' 메뉴(`menu_open`). 빈 곳을 누르면 선택 취소
- **속성 지형**: 숲=풀, 물가=물, 용암=불, 모래밭=바람. 자기 속성 = 이동 비용 1·공격 ×1.2·받는 피해 ×0.8, 다른 속성 = 이동 2·공격 ×0.8·받는 피해 ×1.2 (`GameData.terrain_affinity`, `TERRAIN_*` 상수). 엄폐·화상·물가 회복·사거리 보너스는 없앰. 마법진(회복)·바위만 따로. 원작 수치는 확인 못 함
- **마법진 소환**: 소환 칸 = 정령사 옆 + 그 진영이 차지한 마법진 (`_summon_cells`)
- **보관함 통합**: 파티·보관함 구분 없음 (`GameState.party` = 계약 정령 전부, 6마리 제한 없음, `storage`는 옛 저장 호환용). 첫 번째 = 선봉
- **공용 UI** `SpiritList`(속성 탭 + 정렬 버튼: 기본/추천·레벨·이름, flags에 기억) · `EquipEditor`(장비 칸 + 능력치 비교) — 거점과 전투 소환 창이 같이 씀
- **큰 소환 창**: 소환을 고르면 아래 패널이 화면의 약 70%로 커짐 → 목록 + 고른 정령 상세·장비 + [소환하기]. 장비는 소환 전에만
- **마을 의뢰**: 여관 없앰. 마을 지점의 `quests` (type: clear/capture/defeat, element 표식, reward). `GameState.quests` 저장, `quest_event()`(계약·퇴치 때), 마을에 돌아와 보고 → 보상. 지도 패널에 진행 중 의뢰 표시
- 2장 안개 늪은 곁길(`"side": true`), 대사는 방문 순서와 무관하게 수정
- 테스트: `SMOKE_FROM_CH2=1`로 2장부터 자동 진행 가능

### 경험치 (최신, 사용자 확정 규칙)
- 전투가 끝날 때 나눠 주지 않고 **행동할 때마다 바로**: 공격(기본·스킬·반격·정령사 공격)으로 입힌 피해 비율 × `xp_reward × 0.5`, **마무리(쓰러뜨림)** 하면 `xp_reward` 추가, 디스펠 성공도 `xp_reward`, 회복·버프·디버프 스킬 3 (`BattleLogic.HIT_XP_RATIO` 등). 소환 안 한 정령은 경험치 없음
- 레벨업은 전투 중 그 자리에서 (LEVEL UP 연출), 결과 화면에 정령별 획득 경험치 요약 (`_award_xp`, `_xp_summary`)

### 골드 표시 · 기타 (최신)
- `UIKit.gold_badge(양, 크기, 앞글자, 설명)`: 도트 동전(`assets/ui/coin.png`, `tools/art/ui_icons.py`) + 금색 숫자 알약. 보상 줄 `"@gold:<양>:<설명>"`은 `UIKit.reward_line()`이 알약으로 그림 (전투 결과·이벤트 결과·스테이지 보상). 지도 오른쪽 위·거점·상점에 사용
- 하린 초상화 `npc_harin_<속성>` 4종 (지역 속성 따라감, 표식 `@harin_reg`, 스테이지 summoner `portrait` 필드)
- 명령 메뉴 자리: 오른쪽/왼쪽 × 가운데/위/아래 중 이동 칸·대상·튜토리얼 표시를 가장 적게 가리는 곳 (`_place_cmd_menu`). 1-1 고르기·이동·대기 단계에서는 메뉴 숨김
- 지형 `hill`은 이름·그림을 **모래밭**으로 변경 (효과는 그대로: 이동 2·바람 1, 바람 +20%, 원거리 +1)

### 대륙 지도 · 2장
- `data/chapter2.json`: 2장 「안개 너머의 길」 — 지점 그래프 `nodes` (type: battle/boss/event/shop/town, `pos`, `links`, `goal`). 지역 = 다음 지역(라이벌 속성, `"region": "next"`)
- 지역 표식: `@reg_a/@reg_b/@reg_guardian/@reg` = 지금 챕터 지역 속성 기준 (`GameState.active_chapter`, `chapter_element()`), 대화 치환 `{region}` `{reg_guardian}`
- 1장 `stages`는 `GameData._setup_chapters()`에서 일직선 지점으로 자동 변환. 지점 열림 = 이어진 지점을 지나왔는가 (`node_unlocked`), 챕터 열림 = 이전 챕터 `goal` 지점 클리어
- `world_map.gd` 전면 개편: 대륙 지도(4지역 + 무색의 도시) / 지역 지도(지점·길·정령사 말 이동), 상점(재고는 승리 3회마다 바뀜, 반값 판매)·마을(회복·저장·거점)·이벤트(선택지 효과: gold/item/heal/spirit/battle) 창
- **골드** `GameState.gold` (새 게임 50, 승리 = 10 + 정령 레벨 합×3, 스테이지 보상 `rewards.gold`). 장비 가격 `equipment.json` `price` 또는 능력치로 계산(`GameData.equipment_price`)
- 대화·튜토리얼·화자 초상화는 모든 챕터에서 찾음 (`GameData.dialogue`, `tutorials_for`, `speaker_portrait_table`)

### 스토리 / 진행
- `data/chapter1.json`: 1장 「끊어진 실」 6 스테이지 + 대화 전부(시작 속성에 따라 고향/적/수호 정령 변경)
- 월드맵(`scripts/ui/world_map.gd`), 대화창(`scripts/ui/dialogue_box.gd`), 진행 저장
- **(최신) 대화창 화자 초상화**: 주인공은 왼쪽, 다른 인물은 오른쪽(좌우 반전)에 미끄러지며 등장. 화자 → 초상화는 `GameState.speaker_portrait_key()` (`{player}`/`{rival}`/`{guardian}`은 코드에서, NPC는 `chapter1.json`의 `speaker_portraits`)
- **(최신) 월드맵 적 초상화**: 스테이지 정보 패널에 등장 적 카드(보스·정령사 금테, 무작위 정령 "?") — `GameState.stage_preview()`(`GameState.cleared_stages/flags`)

### 아트
- 혼합형 확정: **전투=도트(32×32)**, 도감/대화/초상화=2D SD 일러스트
