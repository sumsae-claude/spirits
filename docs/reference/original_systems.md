# 원작(Spiritual Soul 1·2) 시스템 참고 요약

> 사용자가 제공한 나무위키 문서(시리즈 메인, 아이템 2~17장)를 **시스템·수치 구조 위주로 요약**한 참고 자료.
> 원칙: 원작에서 가져오는 것은 **구조와 수치 규모**까지. 정령·아이템·인물 이름, 스토리, 그림은 **오리지널**로 만든다.
> (정령 문서는 아직 받지 않음)

## 1. 기본
- PC(Windows 95/98) 헥스 SRPG. 1편 1998, 2편 1999, 슈와시스템.
- 정령 수집·육성(도감), 진화, 아이템 합성, 미니게임(유희장, 요리대회), 숨은 이벤트·비밀 상점·20층 던전.
- 전투 장면은 시네마틱 연출, 건너뛰기·간이 전투 옵션 있음.

## 2. 속성·지형
- 상성: 땅 < 불 < 바람 < 물 < 땅 (우리: 바람▶불▶풀▶물▶바람과 같은 고리, 풀=땅).
- 속성 성격: 땅 = 맷집(이동·마력 낮음) / 물 = 마력(공격·체력 약함) / 바람 = 민첩·이동(공격·체력 약함) / 불 = 공격(마력 낮음, 성장 가장 좋음).
- 역상성끼리 싸우면 명중·피해·회피 모두 손해.
- 지형도 속성을 따름. 이동 지정 시 커서에 유불리 표시: ◎ +20% / ○ +10% / = 0 / △ −10% / × −20%. 마법진은 무조건 +20%.
  - 불 정령은 물 위에서 이동력 크게 감소, 물 정령은 맨땅에서 불리(수풀·마법진에서 유리).
- 마법진은 점령 가능. 아군 마법진으로 순간이동하는 마법 있음.

## 3. 소환·디스펠·친밀도
- 주인공보다 정령을 키워 싸우는 게임. 적 레벨이 주인공 레벨을 따라 오름 → 주인공은 보조 위주.
- 소환한 정령은 **매 턴 MP 유지비**. 주인공 MP가 0이 되면 정령이 야생(중립)으로 돌아가 공격해 올 수 있음.
- 디스펠(해주)은 주인공만. 적 정령사도 디스펠로 아군 정령을 빼앗을 수 있음.
- **친밀도**(하트): 높을수록 디스펠당하기 어려움(최대면 한 자리 %). 자주 소환하거나 속성 향수로 상승, 귀환·쓰러짐 시 약간 하락.
- 장비: 플레이어 마스터는 언제든 교체. 정령은 소환 후 교체 불가(소환 전엔 목록에서 교체 가능).

## 4. 전투 세부
- 명중·회피 있음. 공격받을 때 **반격 / 방어 선택**(방어는 피해 감소, 마법엔 무효).
- 레벨업 시 HP·MP 전부 회복. 일부 정령은 경험치 0(레벨업 불가).
- 상태이상 5종: 독(턴마다 HP 감소), 수면(회복되면 깸, 마법진에서 턴 시작 시 풀림), 혼란(조종 불가, 마스터는 면역), 지체(이동력 1), 석화(행동 불가). 지속 턴 있음(대개 6).
- 상태이상 마법도 경험치를 줌.
- 범위 4단계: 1칸 / mega 반경1(7칸) / giga 반경2(19칸) / tera 반경3(37칸).

## 5. 아이템 체계
### 분류와 수치
- WEAPON(던지는 공격·공격 기술), EQUIP(능력치 장비), MEDICAL(회복·해제), SPECIAL(특수).
- 거의 모든 아이템이 **사용 / 장비 / 합성 재료** 세 가지로 쓰임.
- 수치: 속성, 사정(쓸 수 있는 거리), 범위(1/M/G/T), 명중, 공격력, 상태이상+지속, 가격.
- 장비 효과: 힘·민첩·방어·지능, **매 턴 HP/MP 자동 회복**, **소환·유지 MP 감소(코스트)**, 이동+, 사정+, 소비 MP 감소, 상태이상 내성(25%/50%/무효), 마법 내성, 해주(디스펠) 무효.
- **소지 칸 제한 있음**(엘릭서를 들면 다른 장비 칸이 하나 준다고 서술).

### 합성 (아이템 2개 → 1개)
- 재료 등급 사다리: 하급(룬석) → 중급(룬) → 상급(석판). 이로부터 기본 소재(나무·돌·철광석·미스릴 은·수정·희석·진주조개·사금 등).
- **잠재 속성**: 재료마다 숨은 속성. 같은 계열 + 어떤 속성 재료냐에 따라 결과 속성이 정해짐 → 레시피를 추측할 수 있음.
- 같은 결과에 여러 조합. 정해지지 않은 조합(꽃·약초끼리)은 대개 흔한 결과물(상태이상 가루)이 나옴.
- **숫자 규칙** 예: 과일마다 번호, 두 과일 번호 합으로 잼 등급 결정.
- 합성표: 두 아이템이 만나는 칸의 "?"로 합성 가능 여부 힌트. 성공한 조합은 영구 기록.
- 중심 재료 "마법의 물": + 꽃 → 향수(친밀도), + 약초 → MP약, + 과일/채소 → HP약, + 해제 약초 → 상태이상 해제약, + 고급 채소 → HP·MP약.
- 마법 아이템 3갈래: 재료 + 양피지 → 원서. 원서+원서 → 장비용 책(마법 내성·회복·코스트 감소) / 원서 + 펜과 잉크 → 1회용 두루마리(MP 0, 강함) / 두루마리 + 마법의 서 → 반복 사용 마법서(MP 소모).
- 장비 강화 사다리: 기본 → 철(+철광석) → 미스릴(+미스릴 은) → 속성/마법(+오브·희석·마초석) → 빛·어둠(+석판) → 전설(특수 이벤트). 검·도끼·창·방패·갑옷은 끝까지, 투구·장갑·신발은 초반용.
- 무기 + 무기 조합 무기도 있음.

### 무기 성격
- 검: 힘+민첩 / 도끼: 힘만, 무거우면 이동 −1 / 창: 힘+민첩+사정 +1 / 활: 원거리 공격 기술(사정 6~9) / 지팡이: 힘+지능, 룬석 조합으로 강화·회복 기술.

### 회복·도구 범위 (등급이 오를수록 사정·범위 확대)
- HP약: 20(1명) → 40(1명) → 75(1명) → 30+MP15(사정5, 반경1) → 50(사정5, 반경2), 최고급 HP·MP 99(1명). MP약도 같은 구조.
- 회복 두루마리: 하급 사정4·반경2 → 상급 사정6·반경2 → 최상급 사정9·반경3(전부 회복 + 상태이상 해제).
- 향수(친밀도)는 사정 0 → 정령이 직접 들고 사용.
- 해주가루(디스펠 도구): 속성 전용 50%, 범용 40%, 사정 1. 상대 친밀도가 높으면 명중 하락.
- 상태이상 도구: 가루(사정3·1칸·명중 낮음·쌈) / 향수(사정4·반경2·비쌈). 술은 회복 + 상태이상(사정4, 명중 100%) → 적에게 먹이기도 함.
- 음식: 회복 + 6턴 강화(고기=힘, 다리고기=민첩, 얼룩알=이동), 알은 반경1 회복.
- 장비가 주는 기술: 아뮬렛·수호부적(범위 회복·해제·공격), 신옥(범위 강화), 챰(사라지지 않는 자기 회복, 사정 0).

### 특수
- **엘릭서**: 들고 있다가 HP 0이 되면 소모되어 부활. 중간 보스·강한 정령이 들고 있는 경우가 많아 디스펠로 빼앗음.
- 영구 능력치 상승(비약, 마법의 서 지능+3, 특정 꽃), 레벨 상승 아이템(변화의 보옥).
- 이동 +2~+3, 사정 +1~+2 장비, 이동한 칸에서 아이템을 반드시 줍는 장비.
- 분장(3종 세트)을 다 입고 특정 장소에 가면 반복 보상.

### 기타 (18~19장)
- 요리도구: 기본 → 마법(+미스릴 은) → 전설(+빛의 석판) 3단 강화. 장비 효과는 미미, 요리대회(미니게임)용.
- 보물: 팔아서 금화를 버는 아이템. 금화도 아이템으로 취급.
- 귀환 깃털: 사정 3, 대상 유닛을 전장에서 후퇴시키는 도구.
- 수집·이벤트용 특수 아이템(정체불명의 돌, 외전 열쇠 등).

## 6. 이야기 구조 (참고만, 내용은 쓰지 않음)
- 1편: 정령과 사람이 사는 세계, 봉인이 풀린 악이 균형을 깨 정령들이 흉포해짐("대변동"), 어린 정령사 4명이 각자 여행하다 중반에 합류.
- 2편: 7대륙 중 한 대륙, 불길한 혜성, 잠든 수호정령, 예언, 주인공 2명(불·물)이 함께 다니다 갈라짐. 상인 퀘스트 비중 큼.

## 7. 정령 규모 (메인 문서 데이터 목록 기준)
- 3단 진화 계열: 불 6, 바람 4, 땅 5, 물 5 = 20계열 → 60종.
- 4대 정령 4, 특수 3, 신룡 4(속성별), 비정령 적 12(3종×4속성), 수호정령 4, 여신 등 → 약 90종.
