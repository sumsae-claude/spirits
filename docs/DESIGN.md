# 정령계약자 — 게임 기획서

> 버전 0.1 · 전투 프로토타입 v0.7 기준 · 이 문서는 개발하면서 계속 갱신합니다.

## 1. 한 줄 소개

**정령사가 되어 폭주한 정령의 끊어진 실을 디스펠로 풀어 주고, 계약한 정령을 소환해 싸우는 세로 화면 헥스 전략 RPG.**

- 장르: 턴제 헥스 SRPG + 정령 수집·육성
- 플랫폼: Android 우선 (Godot 4, 추후 iOS·PC 고려)
- 판매 형태: **패키지형** (무료 체험 → 정식판 1회 구매), 오프라인 싱글 플레이
- 목표 분량: 5챕터 · 스테이지 35~40개 · 15~20시간 + 엔드 콘텐츠

## 2. 상품 전략

### 2.1 왜 패키지형인가
- 꾸준한 운영(이벤트·시즌·서버)이 필요 없어 **1인/소규모 팀이 유지보수 가능**.
- 완전 오프라인 + 로컬 저장 (선택: Google Play 게임즈 클라우드 저장).
- 모든 콘텐츠가 데이터(JSON) → 출시 후 밸런스 패치는 데이터 수정만으로.
- 출시 후: 버그 수정 + (반응 좋으면) **유료 DLC 챕터 1~2개**.

## 3. 세계관·스토리 — 「계약은 사슬인가, 인연인가」

### 3.1 배경
- 옛날 네 정령왕이 세상과 **대계약**을 맺어 바람·불·풀·물의 균형을 지켜 왔다.
- 대계약의 **실**이 끊어지면 정령은 이성을 잃고 **폭주**한다 → 지금의 야생 정령.
- **디스펠** = 엉킨 실을 끊고, 정령이 받아들이면 새로 인연을 잇는 기술. (계약 = 구원)

### 3.2 인물
| 인물 | 설명 |
|---|---|
| 주인공 (정령사) | 견습 정령사. 처음 고른 속성의 지역이 고향. 혼자 여행한다 |
| 세라 (라이벌) | 주인공과 반대 성향 속성의 정령사. 툴툴대지만 실력파. 이벤트 전투에서 동행하기도 |
| 회색 결사 | "정령은 어떤 계약에도 묶여선 안 된다"는 정령사 집단. 대계약의 실을 끊고 다님. 과거 강제 계약의 역사 때문에 주장에도 일리가 있다 |
| 수호 정령 | 지역마다 한 체. 결사에게 실이 엉켜 폭주 → 보스. 구하면 전설 정령으로 동료가 됨 |

### 3.3 챕터 구성
| 챕터 | 지역 | 핵심 사건 |
|---|---|---|
| 1 | 고향 (시작 속성) | 첫 폭주 정령, 첫 디스펠, 세라와의 만남, 결사의 첫 등장, 고향 수호 정령 구출 |
| 2~4 | 나머지 속성 지역 | 각 지역 정령사와 게스트 전투, 결사 간부, 수호 정령 |
| 5 | 무색의 도시 | 결사 본거지. 대계약을 다시 맺을지 / 모두 풀지 **선택 → 엔딩 2종** |

- 지역 이름: 바람 = 바람의 고원 마을, 불 = 불꽃 골짜기, 풀 = 초록숲 마을, 물 = 물안개 호숫가
- 라이벌 속성 = 시작 속성의 **상성 중립** 속성 (바람↔풀, 불↔물)

### 3.4 다른 정령사 플레이
- **정령사 협회**에서 **정령사 증표**(스토리·탑·업적 보상)로 다른 속성 정령사 해금.
- 계약 정령·장비는 공유, 정령사 레벨·스킬은 정령사마다 따로.

## 4. 핵심 시스템

### 4.1 전투 (구현됨 — 프로토타입 v0.7)
- 세로 8×10 헥스 맵, 무작위 지형(숲·물가·언덕·용암·마법진·바위).
- 라운드 = 아군 턴 → 적 턴. 아군은 유닛을 자유 순서로 선택, 이동 1 + 행동 1, 이동 취소/미리보기.
- **정령사**가 직접 출전, 쓰러지면 패배. 소환(연속 소환, 한도)/귀환/디스펠/스킬/공격.
- 상성: **바람 ▶ 불 ▶ 풀 ▶ 물 ▶ 바람** (×1.5 / ×0.75).
- 적: 야생 정령, 적 정령사(소환·회복·공격 AI). 적 정령사의 정령도 디스펠로 빼앗기 가능(×0.6).
- 후퇴·패배해도 디스펠로 계약한 정령은 유지.

### 4.2 보스: 수호 정령 (챕터 1 체험판에서 구현)
- 처음엔 디스펠 불가, HP가 1 밑으로 내려가지 않음.
- HP 30% 이하 → **"실이 드러났다!"** → 디스펠 가능 (성공률 +30%).
- 디스펠 성공 = 스테이지 클리어, 수호 정령이 전설 정령으로 합류. 호위 정령은 물러남.

### 4.3 성장·수집 (예정)
| 시스템 | 내용 |
|---|---|
| 정령 도감 | 4속성 × 4계열 × 3단 진화 = 48종 + 전설 4 + 히든. 달성 보상 (10/25/50%) |
| 색이 다른 정령 | 약 1/50, 능력치 동일·외형만 다름 (수집 재미) |
| 조건 진화 | 레벨 + 조건 (예: 용암 위에서 레벨업, 마법진 위 승리, 친밀도) |
| 계승 | 정령을 합쳐 스킬 1개 물려주기 |
| 정령사 스킬 | 스킬 서로 획득, 4칸 장착(로드아웃). **정령의 제단**: 정령석으로 스킬 서·장비 랜덤 획득 |
| 장비 | 드랍 / 상점 / 강화(+1~+5) / 세트 효과. 정령·정령사 모두 장착 |
| 엔드 콘텐츠 | 무한의 탑, 하드 모드, 2회차, 업적 |

## 5. 아트 방향

- 정령은 **귀여운 정령** 콘셉트.
- 추천: **혼합형**
  - 전투·월드맵 = **도트** (정령 48×48px, 4프레임 대기·공격, 헥스 타일 64px) → 다수 에셋을 저비용·일관성 있게.
  - 도감 카드·대화 초상화·전설 정령 = **2D SD 일러스트** → 스토어 경쟁력.
- 시안: `art/concepts/` (대표 정령 4종의 도트 / 2D 비교)
